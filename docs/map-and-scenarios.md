# 합성 지도와 장시간 주행

| 지도 | 도로·지형 | 앱 시나리오 |
|---|---|---|
| M01 | 간선과 생활도로가 연결된 도심 격자 | L01, L04 |
| M02 | 본선과 곡선 진출입 램프 | L02, L11 |
| M03 | 직선 터널과 우회 생활도로 | L06, L07 |
| M04 | 12m 간격 본선·서비스도로 | L10, L12 |
| M05 | 서로 다른 노드 레벨의 상·하부 도로, 연결 램프 | L13 |
| M06 | 하천, 두 교량과 접속 도로 | L08, L17 |
| M07 | 저속 곡선과 T자 분기 | L03, L14 |
| M08 | 굴곡 도로, 능선 녹지, 터널 | L09 |
| M09 | 간선, 서비스도로, 단지와 합류 | L05, L15 |
| M10 | 도심에서 고속화도로·터널·램프·교량으로 이어지는 회랑 | L16, DEMO_LONG |

L01–L17은 90–120초, DEMO_LONG은 180초다. 카탈로그 행에는 지도 ID, 한국어·영어 제목과 설명, 장애 분류, 시간, 평가용 여부, 대표 주행 여부가 있다. 카탈로그 순서가 선택 목록에 반영된다. E01–E10은 지도별 별도 시드와 장애 시각을 사용한다. E01·E07은 달라진 계획 경로, E02는 위치 점프를 추가한 이탈 패턴을 사용한다.

## 원본과 경계

- v1 S 계열과 15초 DEMO는 기존 원본을 유지한다. v1 호환 로더는 같은 좌표의 도로 끝점에 같은 노드 ID를 부여한다. 기존 판정과 가상 시각별 상태는 [체크섬](legacy-replay.sha256)으로 검사한다.
- v2는 `fixtures/extended/catalog.json`, `maps/`, `scenarios/`, `evaluation/`로 구성한다. 지도·시나리오 스키마는 2, 경로 스키마는 1이다. 시나리오는 지도 ID, 계획·실제 경로, 관측, 정답과 고정 기대 이벤트를 보유한다. 지도/시나리오/경로 SHA-256과 시드는 평가 JSON에 기록한다. 경로 SHA-256은 방향성 에지 ID를 줄바꿈으로 연결한 UTF-8 문자열의 해시다.
- 카탈로그는 256KiB, 지도 64개 및 항목 256개 이하로 읽는다. 지도 ID와 시나리오 ID로 정규 경로를 조립한다. 지도와 시나리오 합산 4MiB, 관측 5,000개, 도로 선분 512개, 폴리곤 512개·정점 4,096개, 라벨 64개를 상한으로 둔다. 지도 좌표는 축별 ±100km 이내이며 에지 양 끝점은 해당 노드 좌표와 정확히 일치해야 한다. v2 계획·실제 경로의 에지 반복은 금지한다.
- 도로 끝점과 허용 전이는 명시한다. 반대 방향 에지는 별도 ID를 갖고, 시각화에서 같은 도로로 표현할 때는 `physicalId`를 공유할 수 있다. M05 상·하부 도로는 같은 평면 좌표에 서로 다른 노드 ID를 사용한다. 시험은 허용 전이 분포와 연결 컴포넌트 크기로 10개 지도의 위상 차이를 검사한다.

## 생성과 평가

도로망과 연결은 `tools/extended/maps.py`에 있고, 표현 개정 2의 필지·도로명·산책로는 `terrain.py`에서 조립한다. `driving.py`는 가감속·정차를 포함해 200ms 단위로 실제 궤적을 만든 뒤, 1초 단위 GPS에 결정적 잡음과 장애를 주입한다. 신호 손실은 발행 생략, 지연은 수신 시각 변경, 위치 점프는 좌표 변경으로 모델링한다. 경로 이탈은 주행 에지 자체를 바꾼다. `generate.py`의 기대 이벤트는 이 입력 설계에 맞춰 선언한다.

```bash
python3 -B tools/extended/generate.py
python3 -B tools/extended/check_terrain.py
./gradlew :core:simulation:run --args='fixtures/extended build/reports/extended.json build/reports/extended.md'
```
