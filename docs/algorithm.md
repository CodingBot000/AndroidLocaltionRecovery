# 위치 판정과 평가 방식

## 검증과 매칭

관측 모델의 숫자·시각·방향을 검사하고 미래 시각, 중복 ID, 측정 순서, 수신 지연 순으로 검사한다. 측정 순서를 통과한 관측은 품질이나 이동 오류로 거부되더라도 측정 watermark를 갱신한다. 채택된 위치와 측정 시각은 ACCEPTED에서만 바뀐다.

Accuracy 20m 이하는 정상 검사 대상으로 삼고, 60m 이하는 저품질로 분리한다. 최대 수신 지연은 3,000ms다. 이동 허용 거리는 45m/s × 측정 시각 차(초) + min(두 accuracy 합, 30m)이다. 정상 추적과 재획득 첫 후보에는 마지막 채택 관측을, 이어지는 후보에는 직전 후보를 사용한다.

도로 선분의 투영 후보 중 60m 이내를 비교한다. 거리·방향·연결성·계획 경로 가중치는 각각 0.65·0.20·0.10·0.05다. 거리 비용은 거리/반경, 방향 비용은 최소 각도 차/180°, 연결성 비용은 같은 도로 0, 연결 0.5, 그 외 1이다. 계획 경로 비용은 경로 안 0, 경로 밖 1이다. 속도 1m/s 미만 또는 heading·정상 속도 결측이면 방향을 빼고, 유효한 직전 매칭이 없거나 LOST·RECOVERING이면 연결성을 빼고 재정규화한다. 도로별 최저 비용을 비교해 최저가 0.75를 초과하면 NO_MATCH, 차점과의 차가 0.08 미만이면 AMBIGUOUS다. 진단 순서는 비용·도로 ID·선분 순서다. 평행 도로 동률을 강제로 확정하지 않는다.

## 신호 손실과 추정

Tick은 200ms마다 발생하며 같은 시각의 모든 관측을 먼저 처리한다. 종료 시각에 Tick이 없으면 한 번 추가한다. TRACKING·DEGRADED에서 마지막 채택 측정 이후 3,000ms 이상인 Tick에 LOST로 전이한다.

DR은 채택 관측의 매칭 위치·도로·속도·측정 시각을 하나의 기준점에 보존한다. 관측 속도가 누락되면 직전 채택 원시 관측과의 측정 간격으로 속도를 구한다. 기준점이 없거나 모호한 분기, 경로 끝, 측정 이후 15,000ms 한도에 도달하면 마지막 채택 위치를 표시한다. 정차 속도 0은 유효하다.

복구 후보는 측정 간격과 가상 수신 대기를 각각 2,000ms로 확인한다. 기존 후보의 수신 만료 여부와 측정 간격을 이동 조건보다 먼저 확인하며, 체인이 끊기면 새 첫 후보로 다시 검증한다. 수신 시각이 만료 시각과 같으면 관측이 우선한다. 연속 후보 3건 중 마지막 관측만 채택한다. 경로 이탈·복귀는 신뢰 가능한 채택 관측 3건으로 확정하고, 같은 이탈 구간에서는 권고를 한 번만 발행한다.

## 평가

상태 전이와 reason code는 원본 fixture에 정의한 기대값과 비교한다. 오류 주입 전 정한 Ground Truth로 측정 시각의 원시·채택 오차와 Tick 시각의 DR 오차를 따로 집계한다. 각 GPS 입력은 fixture 순번으로 식별한다. 보류 후보의 후속 결과는 최초 관측 판정과 별개로 집계한다. 중앙값과 nearest-rank p95를 제공하고 분모가 0이면 N/A로 표시한다.
