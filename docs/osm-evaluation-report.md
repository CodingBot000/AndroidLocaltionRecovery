OL 및 ODEMO_LONG은 OSM 도로 위의 앱 가상 주행이며 OE는 별도의 평가 사례다.


분포의 중간값은 중앙 표본의 평균으로, p95는 nearest-rank 방식으로 계산한다. 원시·채택·DR은 표본 범위가 다르며 같은 관측의 비교는 JSON의 paired 항목을 사용한다.
가상 입력을 재생하여 측정했으며 실제 GNSS 정확도나 단말 처리량을 뜻하지 않는다. JSON 원본은 fixture 체크섬, 엔진 설정, 표본 수와 분포, 복구·이탈 지표를 포함한다.
