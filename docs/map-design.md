# 합성 지도 시각 설계 이력

[현재 OSM 지도 설계](korea-map-design.md) · [최신 화면](osm-visual-verification.md)

실제 OSM 전환 전 합성 지도 설계와 검증 조건을 보존한 기록이다.

기준선 `84ae43d`에서 도로 노드·에지·전이와 모든 계획/실제 주행, Ground Truth, 관측·독립 기대값을 고정했다. 새 지도 데이터는 같은 v2 fixture의 표현 개정 `visualVersion=2`에 들어간다. `RoadNetwork`는 기존 차량 도로를 제공한다. `MapVisualData`의 구역, 필지, 건물, 수면, 산책로, 라벨은 화면 표현에 사용된다.

## 공간 구성

지도별 방향을 지정한 가로변 경계와 깊이에서 필지를 만든다. 주거 필지는 작은 단독 footprint, 상업 필지는 가로에 붙는 건물열과 안뜰, 산업 필지는 큰 footprint와 넓은 간격을 사용한다. 직사각형과 L자 평면을 섞고 건물은 지형·산책로 및 도로 완충 구간을 피해 배치한다. 도로 중심선 기준 완충은 생활도로 8m, 보조도로 11m, 간선 14m, 고속도로 19m, 램프 13m다. 지도 화면의 도로 stroke 폭과 독립적인 검사용 여유 거리다.

| 지도 | 구역 구성 |
|---|---|
| M01 | 도심 격자의 가로변 상업 블록, 안뜰, 정형 도시 공원과 남쪽 녹지 |
| M02 | 도색이 다른 고속화도로·진입로, 교차 쪽 물류 필지, 북쪽 녹지 |
| M03 | 터널 주변의 넓은 능선 녹지, 입구·출구 쪽 취락, 지상의 우회로 |
| M04 | 12m 간격 본선·서비스도로, 양측 산업·상업 앞마당, 별도 산책로 |
| M05 | 고가·하부 도로와 연결 램프, 입체교차 옆 공원 및 상업 필지 |
| M06 | 폭이 변하는 하천과 2개 교량, 양안에 면하는 주거·상업 구역 |
| M07 | 곡선 생활도로를 향한 작은 필지, T자 교차, 정원 사이의 녹지와 산책로 |
| M08 | 산지 능선과 굽은 도로, 터널, 듬성듬성 놓인 주거 필지 |
| M09 | 간선 분기와 각도를 맞춘 공업·상업 앞마당, 합류 간선 및 녹지 |
| M10 | 도심 상권에서 고속화도로·터널을 거쳐 산업 지구, 큰 녹지, 하천과 교량으로 이어지는 회랑 |

`tools/extended/generate.py`는 고정 시드로 정규 JSON을 생성한다. `check_terrain.py`는 다각형 유효성, 필지 내부 배치, 건물 중첩과 도로 완충, 산책로의 건물·수면 침범 및 물을 건너는 자동차 도로의 교량 여부를 검사한다. [기준선 도로망 해시](map-quality-topology.sha256)

## 렌더링과 카메라

- Detail의 도로 외곽/내부 폭은 생활 7/5dp, 보조 11/8dp, 간선 16/12dp, 고속 21/16dp, 램프 10/7dp다. 같은 레벨에서 외곽을 모두 그린 후 내부를 그리고, 다음 상위 레벨로 넘어간다. 교량·고가는 외곽을 2dp 넓혀 하부 도로와 분리한다. 산책로는 1.5dp 점선이다.
- 계획 경로는 Detail/Mid/Overview에서 각각 7/5.6/4dp이고 halo 전체 폭은 내부선보다 3.5dp 넓다. 터널 구간은 회색 케이싱, 중앙 대시, Detail의 입출구 표시를 사용한다. 지오메트리는 기존 중심선과 둥근 stroke join을 사용한다. 노면·경로·마커는 같은 투영을 공유한다.
- Follow 기본 가로 범위는 365m이고, 안전한 차량 표시점을 뷰 높이 61%에 놓는다. Overview는 경로 bounds에 19dp padding으로 맞춘다. 가로 650m 미만은 Detail, 650–1,500m는 Mid, 더 먼 범위와 Overview 모드는 단순화한다. Overview에서 1,250m보다 좁은 지도는 주변 생활도로를 유지한다. 건물 footprint는 Detail에서 그리고 다른 축척에서는 필지와 구역을 남긴다.
- 라벨은 가시 선분에 맞춰 회전하며 읽기 방향을 보정한다. 지도·구조 라벨은 11sp, 일반 도로는 10sp다. 화면 투영 직사각형에 따라 잘림·중복·충돌을 확인하고 차량·원시 위치·카메라 버튼 주변을 피한다. 제한은 Detail 6개, Mid 5개, Overview 4개다.
- 채택 차량은 24dp 수준의 방향 화살표이며 방향값이 없으면 원형 마커를 사용한다. 추정은 마름모와 점선, 마지막 확인 위치는 중립 원, 원시 관측은 십자, 가상 실제 위치는 사각형이다. 가용한 원시 정확도 반경은 화면 최소 변의 25%까지 표시한다.
- `ui:map`은 장면당 월드 Path와 bounds를 캐시한다. 카메라 이동 시 같은 Path를 변환하고 가시 범위 밖의 도로·지형을 생략한다. 라벨·오버레이는 화면 계산으로 그린다. 카메라와 스타일은 엔진 상태를 변경하지 않는다.
